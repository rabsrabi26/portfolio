Model assumptions, scheduler logic and browser-port notes

This Lab is based on the uploaded MIMO-Scheduling-Simulation-Reviewed-v2 package: default_config.m, generate_users.m, calculate_channel.m, scheduler_simulate.m and run_experiment.m. It uses a 500 m cell, users uniform by area, 10 MHz configured bandwidth, −104 dBm noise power, 30 dBm transmit reference power, 30 dB path loss at 1 m, path-loss exponent 3.5, 8 dB log-normal shadowing, 0–10 ms arrivals and service workloads of 1–5, 2–8 and 5–15 ms.

Each antenna is modelled as an independent service server. Channel gain is converted to SNR and Shannon spectral efficiency, then normalised into a per-user rate factor. Priority combines distance and service class; Multilevel Queue uses strict distance-band priority and the same within-queue priority rule; Round Robin uses a 2 ms preemption quantum; Proportional Fair uses a 1 ms interval and 10 ms exponential averaging; Max C/I chooses the eligible user with the highest SNR. A user cannot occupy more than one antenna at a time.

Browser-port correction: the reviewed MATLAB event loop can stall when every antenna is idle and no user has arrived yet: it keeps selecting the same idle server while other idle-server timestamps remain at zero. The browser port advances to the next arrival or active service event, then dispatches all idle servers. This preserves the intended event-driven scheduling model and prevents a non-advancing loop. The browser uses a deterministic JavaScript random stream, not MATLAB's exact mt19937ar stream, so individual numeric results will differ even with the same seed.

Scope: this package is a large-scale channel-aware multi-server scheduling abstraction, not a complete physical-layer Massive MIMO simulator. It does not implement channel vectors, precoding/combining, antenna correlation, spatial multiplexing or multi-user interference. The configured bandwidth is documented in the model, while the current channel calculation uses the configured noise and transmit powers to derive SNR and spectral efficiency.

05 / research

Scheduling smarter in 5G massive MIMO.

BSc thesis, IUBAT, Fall 2020 · Supervisor: Md. Rashedul Islam

Performance Evaluation of Different Scheduling Algorithms for Resource Allocation of Massive MIMO in 5G

Massive MIMO base stations have more antennas than users, but deciding who gets which resource, and when is still hard when users have different channel quality and different latency needs. Classic schedulers (Round Robin, Proportional Fair, Max C/I) ignore service urgency.

The thesis proposes two lightweight alternatives and evaluates them against those baselines in MATLAB: 50 runs per point, five metrics, an ANOVA with Tukey post-hoc tests.

5GMassive MIMOSchedulingQoSMATLAB

The two algorithms

Location-and-Service Priority. Each user gets a score P = α·(1 − d/R) + β·S combining proximity to the base station with a service-type weight (voice/video 1.0, text 0.5, data 0.2), then users are served in score order. Defaults: α = 0.7, β = 0.3.

Multilevel Queue. Users are first grouped into four distance rings, then priority-scheduled inside each ring, which suits clustered crowds like stadiums.
